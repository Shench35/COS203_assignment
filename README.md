# Grade Checker - COS203 Assignment

A simple Python grade checker program built two ways.

## Task 1 - Single File with Functions
Run:
```
python task1_grade_checker.py
```

## Task 2 - Modular (Separate Files)
Four separate modules inside the `module/` folder:
- `input_module.py` - gets the score from the user
- `logic_module.py` - calculates the grade
- `output_module.py` - displays the result
- `main.py` - runs the program

Run:
```
cd module
python main.py
```

## Grading Scale
| Score | Grade |
|-------|-------|
| 70 - 100 | A |
| 60 - 69 | B |
| 50 - 59 | C |
| 45 - 49 | D |
| 0 - 44 | F |
